# ADS_pandas — Team Pandas

Applied Data Science group project, University of Bristol.

We study the relationship between COVID-19 social media activity and government policy across the Anglosphere (March 2020 – June 2022), using the IEEE COVID-19 Twitter dataset, OxCGRT, and WHO data.
